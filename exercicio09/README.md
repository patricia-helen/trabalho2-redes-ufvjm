**Observação:** Observou-se o processo DORA (Discover, Offer, Request, Acknowledge) para alocação dinâmica de endereço IP. A captura registra a busca em *broadcast* (Discover), a oferta pelo servidor DHCP (Offer), a requisição formal de *lease* do IP pelo cliente (Request) e a confirmação final concedendo as configurações de rede (ACK).
