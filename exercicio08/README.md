# Exercício 8: Tráfego ICMP (Ping)
**Integrantes:** Patrícia Helen Ribeiro Moreira

**Observação:** Identificou-se a troca bidirecional de mensagens ICMP Echo Request e Echo Reply. A análise detalhada dos pacotes permitiu verificar o identificador de sequência e mensurar o Round Trip Time (RTT), que reflete a latência de rede entre a máquina cliente e o roteador/servidor de destino durante o teste de conectividade.
