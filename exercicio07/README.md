# Exercício 7: Resolução de Nomes via DNS
**Integrantes:** Patrícia Helen Ribeiro Moreira

**Observação:** Capturou-se a consulta DNS (Query) do tipo A enviada ao servidor DNS da rede local solicitando o endereço IP de um domínio. O pacote de resposta (Response) retornou com sucesso o domínio pesquisado, eventuais *aliases* (CNAME) e a lista de endereços IPv4 correspondentes, essenciais para o posterior estabelecimento das conexões TCP e HTTP.
